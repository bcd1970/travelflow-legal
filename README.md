# TravelFlow — legal documents

Public hosting for the legal documents of the **TravelFlow** Android app
(package `com.bcd.traveltracker`).

- **Privacy policy:** https://bcd1970.github.io/travelflow-legal/
  ([markdown source](PRIVACY-POLICY.md))

The app's source repository is private. This repository exists only so the
privacy policy has the stable public URL Google Play requires, and so the
app can link to it. Content here is generated from `PRIVACY-POLICY.md` in
the app repository; edit it there.
